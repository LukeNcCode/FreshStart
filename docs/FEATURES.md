# FreshStart 功能清单（v0.2.0-alpha.18）

Windows 11 开荒工具。除明确标注「不可回滚」的卸载/移除类操作外，写操作先备份、失败自动回滚、可撤销；不采集、不上传任何数据。

## 总览

| 页面 | 功能 |
|---|---|
| 开荒工作台 | 首页概览、快捷操作（重启资源管理器、电源选项、控制面板、设备管理器、磁盘管理、服务、注册表、环境变量、系统属性、CMD、PowerShell）、系统评分 |
| 系统信息 | CPU / 内存 / 主板 / BIOS / 显卡 / 磁盘 / 网卡 / 系统版本 / Build / 激活状态 / 开机时长 / 安装日期，一键复制全部 |

## 核心机制

- **写入管线**：读取当前值 → 备份 → 写入 → 校验，失败自动回滚；注册表白名单；JSON 快照 + 审计历史。
- **本地优先**：所有配置、日志、备份在 `%AppData%\FreshStart`；不采集、不上传。
- **单实例**：命名 Mutex + 命名管道，重复启动毫秒级激活已有窗口。
- **启动性能**：R2R 自包含单文件；冷启动 P50 约 467 ms，热启动约 14 ms。
- **无人值守退出码**：0 成功 / 1 执行失败 / 2 缺少确认 / 3 方案无效 / 4 异常。
